## 🚀 Lab Overview

### Lab 1: Java Basics & Arithmetic Operations
* Basic input/output and syntax practice.
* Unit conversions (temperature conversion, seconds to hours/minutes/seconds).
* Variable swapping and arithmetic manipulation.

### Lab 2: Conditional Statements & Control Flow
* Decision-making using `if-else` blocks and logical operators.
* Fundamental algorithmic problem solving and validation.

### Lab 3: Loops & Menu-Driven Programs
* `AreaCalculator.java`: Interactive menu calculating areas of geometric shapes (triangle, circle, rectangle) using a `do-while` loop and `switch-case`.
* `Factorials.java`: Computes and displays factorials for numbers 1 through 10 using a nested `while` loop.
* `FibonacciSeries.java`: Generates the first 50 Fibonacci numbers using `long` to prevent integer overflow.
* `PrimeNumbers.java`: Identifies and prints all prime numbers from 1 up to a user-defined limit `N`.

## 🛠️ Requirements & Setup

* **Java Development Kit (JDK):** Version 8 or higher
* **IDE / Editor:** VS Code, IntelliJ IDEA, Eclipse, or Command Line

### How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Jatinkaushik123/OOPS-Using-JAVA.git
   cd OOPS-Using-JAVA
   ```

2. Navigate to the desired lab folder and compile the target Java file:
   ```bash
   cd Lab_3
   javac PrimeNumbers.java
   ```

3. Run the compiled class file:
   ```bash
   java PrimeNumbers
   ```
